Developed a robust RESTful API backend for a comprehensive HR Management System using NestJS and PostgreSQL. The system provides complete CRUD operations for employee management, department organization, candidate tracking, and salary administration. Built with TypeScript and Prisma ORM for type-safe database operations, deployed on Render with continuous integration.
