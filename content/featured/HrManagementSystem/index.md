A comprehensive full-stack HR Management System built with modern web technologies to streamline human resources operations. This complete solution features a responsive Angular frontend with Material Design and a robust NestJS backend with PostgreSQL database, providing end-to-end functionality for employee management, department organization, candidate tracking, and salary administration.
