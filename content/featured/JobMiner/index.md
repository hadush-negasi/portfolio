Job Miner is a full-stack web application that scrapes real-time remote job listings from online job sites like RemoteOK. Built with React, Tailwind CSS, and Node.js, it features an intuitive UI with keyword-based search, autosuggestions, and loading feedback. The backend uses Puppeteer and Cheerio to dynamically fetch and parse job data. Deployed on Netlify (frontend) and Render (backend).
